# UMillingSlop 🎮

Top-down action survival shooter game featuring dynamic procedural falling walls, diverse mutant enemy types, responsive combat mechanics, and persistent high score tracking.

## 🌟 Key Features

- **Dynamic 3D Falling Wall System**: Walls collapse and reorganize dynamically across rotating map quadrants every 8 seconds, shifting battle terrain.
- **Unique Mutant Enemies**:
  - **Laser Eye (`laser_eye`)**: Sweeps continuous electric blue laser beams with real-time tracking, red warning lock-on, and custom charging mechanics.
  - **Kamikaze Exploders**: Fast suicide bombers that spawn strictly off-screen for surprise ambushes.
  - **Mutant Variations**: Giant Head, Split Mutant, Double Torso, Floating Hands, and Tiered Elites.
- **Wall Impact Bullet Decals**: Realistic bullet hole decals with metallic borders created dynamically on wall front faces upon bullet hit.
- **Weapon Arsenal & Upgrades**: Switch between Pistols, SMGs, Shotguns, and Snipers with level-up stat enhancements.
- **Persistent High Scores**: High kills, survival time, and level saved locally.

## 🚀 How to Play

1. Open `index.html` in any modern web browser.
2. Use **WASD** to move, **Mouse** to aim and shoot.
3. Evade falling walls and lethal laser sweeps while surviving mutant waves!
